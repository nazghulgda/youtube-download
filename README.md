Small script for downloading videos from youtube.

### ATT:
`ffmpeg` is needed for script to run properly, however installin it via `pip` does not works. It has to be installed globally (i.e. `apt install ffmpeg`)  

Run script by `python pull-yt-video.py` command, enter and paste link to video, 
wait for download to be finished and input 1 to download next video or
input 0 to end the script.  
During download, script will create a `downloads` folder and will put all downloaded videos into that folder.
